# Minimalist Calendar App

A simple, functional, and visually clean single-page calendar application designed for smooth and efficient daily planning.

## Features

* **Single-Page Dashboard:** Access everything you need on one clean interface without navigating between multiple screens.
* **Month-View Navigation:** Easily select specific days or toggle between months using quick tab navigation.
* **Weekly Scheduler:** A central view running Sunday through Saturday broken down into clear, hour-by-hour time blocks.
* **Quick-Add Floating Action Button:** Quickly create new events, meetings, or tasks using the floating action icon (+).
